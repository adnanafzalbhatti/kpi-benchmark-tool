# Corporate & Enterprise PowerPoint Templates

You can place your official corporate PowerPoint template (`.pptx` or `.potx`) in this folder.

### How to use Custom Templates:
1. Open PowerPoint on your computer.
2. Select or create your organization's presentation template with your preferred slide master, fonts, colors, and header/footer branding.
3. Save the presentation as a `.pptx` or `.potx` file inside this `templates/` directory (for example: `templates/Corporate_Template.pptx`).
4. When you launch the **KPI Benchmark & Trial Analysis Tool**, it will automatically detect and select any template found in this folder.

Your generated benchmark decks will seamlessly inherit your official corporate slide master, logos, colors, fonts, and footer formatting.
If no template is provided, the tool automatically uses a built-in clean executive widescreen layout.
